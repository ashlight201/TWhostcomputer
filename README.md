# 关节阻抗控制上位机

基于Qt C++开发的关节阻抗控制上位机程序，用于实现机器人关节的阻抗控制。

## 功能特点

- 实时串口通信，支持多种波特率
- 阻抗控制算法实现（刚度、阻尼、重力补偿）
- 实时数据显示（关节角度、速度、电流）
- 图形化参数配置界面
- 位置闭环控制

## 阻抗控制原理

1. **获取初始位置**：程序启动后，先捕获关节的初始位置
2. **施加外力**：在实际环境中施加外力，使关节角度发生变化
3. **计算误差**：
   - 位置误差：Δθ = θ_current - θ_initial
   - 速度误差：Δω = ω_current（通过差分计算）
4. **计算阻抗力**：
   - F = K × Δθ + B × Δω + G
   - K：刚度系数
   - B：阻尼系数
   - G：重力补偿
5. **生成控制指令**：
   - θ_command = θ_current + F / K
6. **位置闭环**：持续执行上述步骤，直到关节回到初始位置

## 通信协议

### 发送格式
- 标准命令：`a160-150+*`
  - `a`：控制板标识
  - `160`：电机1的目标角度
  - `150`：电机2的目标角度
  - `+*`：命令结束符

- 请求实时数据：`Aa160-150+*`
  - 在命令前加大写字母`A`即可请求反馈数据

### 接收格式
```
angle: angle1  angle2 current: current1 current2mA
```
- `angle1`, `angle2`：两个关节的角度值
- `current1`, `current2`：两个关节的电流值（单位：mA）

## 编译和运行

### 环境要求
- Qt 5.x 或更高版本
- Qt SerialPort 模块
- C++11 支持

### 编译步骤

使用 Qt Creator：
```bash
# 打开项目文件
打开 impedance_control.pro

# 点击构建按钮编译
```

使用命令行（Linux/Mac）：
```bash
qmake impedance_control.pro
make
./impedance_control
```

使用命令行（Windows）：
```bash
qmake impedance_control.pro
nmake  # 或 mingw32-make
impedance_control.exe
```

## 使用说明

### 1. 连接串口
- 点击"刷新"按钮扫描可用串口
- 选择正确的串口和波特率（默认115200）
- 点击"连接"按钮建立连接

### 2. 设置参数
- **刚度系数 (K)**：控制位置恢复的强度，值越大恢复越快
- **阻尼系数 (B)**：控制速度阻尼，值越大运动越平缓
- **重力补偿 (G)**：补偿重力影响
- 输入参数后点击"确认参数"

### 3. 捕获初始位置
- 确保关节处于期望的初始位置
- 点击"捕获初始位置"按钮

### 4. 启动控制
- 点击"启动阻抗控制"开始控制循环
- 此时可以施加外力测试阻抗效果
- 撤去外力后，关节会自动回到初始位置

### 5. 实时监控
- **关节角度**：显示两个关节的实时角度
- **关节速度**：显示两个关节的实时速度（通过差分计算）
- **电流**：显示两个关节的电流值

### 6. 停止控制
- 点击"停止控制"按钮停止控制循环

## 注意事项

1. **安全性**：
   - 首次使用时，建议使用较小的刚度和阻尼系数
   - 确保机械结构安全，避免过大的力矩

2. **参数调整**：
   - 刚度系数不能为零
   - 建议刚度系数从10开始调整
   - 阻尼系数通常设为刚度的1/20左右

3. **串口通信**：
   - 确保串口未被其他程序占用
   - 检查波特率设置是否与硬件匹配
   - 控制频率为50Hz（每20ms一次）

4. **实时性**：
   - 程序使用定时器实现控制循环
   - 建议在性能较好的计算机上运行
   - 避免同时运行大量其他程序

## 技术参数

- 控制频率：50Hz
- 串口波特率：可选 9600 ~ 115200
- 位置阈值：1度（用于判断是否回到初始位置）
- 速度阈值：0.5度/秒

## 故障排除

### 串口无法连接
- 检查串口是否被占用
- 确认设备已正确连接
- 尝试不同的串口和波特率

### 数据读取异常
- 检查通信协议是否正确
- 确认硬件返回数据格式符合要求
- 查看状态信息中的错误提示

### 控制效果不佳
- 调整刚度和阻尼系数
- 确认初始位置已正确捕获
- 检查重力补偿是否合适
